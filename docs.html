Getting started

1. Add OpenUtility to Discord. 2. Return to openutility.bot.nu. 3. Sign in with Discord. 4. Select a server you can manage. 5. Configure the features you need.

The dashboard only lists Discord servers that your account can manage. Bot installation is checked against Discord's guild API.

Dashboard

The dashboard is the main control center. Use the server selector to switch between manageable servers, then use Overview, Configuration, Moderation, Logging and Embed Builder.

The Overview shows member and online counts, bot installation state, access level and channel analytics. The mobile navigation keeps the same controls accessible on smaller screens.

Permissions

Discord permissions are enforced both by Discord and by OpenUtility's backend. Dashboard access is limited to manageable servers, while moderation operations require the acting user and bot to have appropriate permissions.

For production servers, grant only the permissions required for the features you actually use.

Configuration Center

Configure the command prefix, slash/prefix command behavior, welcome messages, AutoMod rules, blocked words and moderation defaults. Select a channel from the server's available channels before saving channel-based settings.

Moderation Center

The dashboard provides timeout, remove-timeout, kick, ban and unban actions. Destructive actions include an additional confirmation prompt. Always verify the user ID and reason before applying a moderation action.

Advanced Logging

Route message, member, moderation and command events to separate Discord channels. Enable only the event categories you need to reduce noise.

Embed Builder

Create an embed, preview it before sending, select the destination channel and use saved templates where available. Treat embeds as public server content and review links and mentions before sending.

Security

Discord OAuth uses a state value to protect the login flow. Dashboard sessions use protected cookies, authenticated requests and CSRF protection for writes. Server permissions are checked on the backend instead of trusting the browser UI.

Never share your Discord OAuth credentials, bot token, session secrets or Redis credentials. If a secret is exposed, rotate it immediately.

Troubleshooting

Server is missing

Confirm you can manage the server in Discord and that OpenUtility has been invited. Refresh the dashboard after installation.

Bot shows as not installed

Make sure the bot was invited with the correct Discord application and that it has access to the server. Reopen the server selector after a few seconds.

Dashboard keeps asking for login

Clear cookies for openutility.bot.nu, sign in again and verify that the backend OAuth redirect is configured for the production environment.

A configuration save fails

Check that the bot is installed, the selected channel still exists and the bot has the Discord permissions required for that feature.

Dashboard or API is unavailable

Check the OpenUtility status page first. If the API is operational, retry the request and inspect the browser/network error before changing server settings.
