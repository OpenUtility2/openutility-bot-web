Getting started

1. Add OpenUtility to your Discord server. 2. Sign in with Discord from the website. 3. Select a server where you have sufficient management permissions. 4. Configure the features you need.

OpenUtility only exposes manageable servers to the dashboard. Discord permissions are checked server-side.

Web dashboard

The dashboard is the control center for server configuration, moderation, logging and embeds. After authentication, choose a server and use the sidebar to open each management area.

Changes are stored per server so your configuration remains available between sessions.

Command reference

/setup /dashboard /automod /moderation /logging /embed /serverinfo /userinfo /reminder /utility

OpenUtility supports slash commands and configured prefix commands where enabled.

Permissions

Server management requires appropriate Discord permissions. Server-side checks are used before protected dashboard actions are performed.

Moderation commands also depend on the permissions assigned to the bot and the acting moderator.

Security

OAuth uses a state value to prevent request-forgery attacks, sessions are encrypted, cookies are HTTP-only and protected, and dashboard write requests require the authenticated session's CSRF token.

Never share your Discord OAuth credentials, bot token, session secrets or Redis credentials.

Troubleshooting

Server missing: confirm the bot is installed and that your Discord account can manage the server.

Configuration fails: refresh the dashboard and verify the bot has the required permissions and that the backend environment variables are configured.

Login loops: clear site cookies, sign in again and verify the Discord OAuth redirect URI matches the backend environment configuration.
