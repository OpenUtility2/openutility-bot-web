About OpenUtility

Discord management, without the clutter.

OpenUtility Bot is an open-source Discord utility and management project built around a simple idea: powerful server tools should be easy to understand and pleasant to use.

What we build

Moderation, advanced logging, server configuration, embeds, utilities and a web dashboard that brings those capabilities together.

Open source

Development happens openly through GitHub. The project is designed to be inspectable, improveable and community-friendly.

Designed for people

Clear controls, useful feedback and a focused interface are prioritized over unnecessary complexity.
