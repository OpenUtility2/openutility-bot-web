Privacy Policy

This page explains the information used by the OpenUtility Bot website and dashboard.

Discord authentication

When you sign in, Discord provides basic account information such as your Discord user ID, username and avatar. The dashboard also requests the Discord server list needed to determine which servers you can manage.

Server configuration

Configuration data for servers managed through OpenUtility may be stored so settings persist between sessions. This can include prefixes, feature settings, channel IDs and embed configurations.

Sessions

The dashboard uses a protected session cookie to maintain authentication. Session data is encrypted server-side and is not intended to be exposed to browser scripts.

Data sharing

OpenUtility does not intentionally sell personal information. Discord is used for authentication and Discord API requests required to provide the bot and dashboard functionality.

Contact

For privacy questions or deletion requests, contact the OpenUtility project through its official Discord community.
